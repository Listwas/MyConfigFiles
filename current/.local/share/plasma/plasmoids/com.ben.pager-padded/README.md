# Icon Pager (Per-Screen) — Plasma 6 applet

A compact virtual-desktop pager for the KDE Plasma panel that shows the
**icons of the apps running on each desktop**, with proper multi-monitor
support: when KWin's *"Switch desktops independently for each screen"*
(per-output virtual desktops) is enabled, the pager shows a separate row
per monitor and highlights the current desktop of **every** screen at once.

Based on [Compact Pager](https://github.com/tilorenz/compact_pager) by
Tino Lorenz and Diego Miguel (GPL-3.0+); heavily extended.



https://github.com/user-attachments/assets/e00b5503-b808-45d8-8d61-a4b3954c21e3



## Features

- App icons inside each desktop cell, so you can see at a glance what's
  running where.
- **Per-screen mode** — one pager row per physical monitor, with the
  monitor order configurable (comma-separated output names).
- Simultaneous highlight of the active desktop on each monitor, not just
  the focused one.
- **Drag & drop windows** between desktops right in the pager.
- Window context menu with **jump-list actions** from the app's `.desktop`
  file (e.g. "New private window"), plus new instance / close.
- Scroll on the pager to switch desktops (optional wrap-around,
  invertible direction).
- Add / remove / configure virtual desktops from the context menu.

## Requirements

- KDE Plasma 6 (Wayland or X11)
- `bash`, `grep`, `awk` — for the jump-list helper and reading the KWin
  per-output setting

## Installation

From the KDE Store: *Add widgets… → Get New Widgets → search "Icon Pager"*.

From source:

```sh
kpackagetool6 --type Plasma/Applet --install .
# upgrade later with:
kpackagetool6 --type Plasma/Applet --upgrade .
```

## Security notes

Jump-list actions are read only from `.desktop` files in the standard
application directories (`~/.local/share/applications`,
`/usr/share/applications`, `/usr/local/share/applications`) — the same
entries your app launcher already executes. All shell arguments are
quoted; desktop-entry field codes (`%u`, `%f`, …) are stripped before
launch.
